A few practical details.

Can I use only my own documents?

Yes. Supply text, Markdown, text PDFs, or public URLs and disable discovery with --no-web. Research still uses your model and Elasticsearch. Local-only ingestion can extract documents without those services.

Where does the research go?

Runs, evidence snapshots, and reports are saved in local SQLite. Browse them in the CLI and export Markdown or JSON. Your model and configured retrieval services process evidence during research.

Do I need Jev?

No. Elasticsearch hybrid retrieval works with reranker none. Enable Jev for an additional relevance-scoring step; it requires a TypeSafe key and makes separately counted requests.

Is this available on a package registry?

The current installation is from GitHub with uv sync --locked. No PyPI or npm release is advertised. The setup guide contains source-install commands.
